# Licensing readiness

Simple arithmetic and the underlying fractions may not themselves be protectable proprietary intellectual property. Legal advice should come from qualified counsel.

Commercial value can instead grow through reliable implementation, SDK quality, developer experience, documentation, provider adapters, notification logic, tested timezone behaviour, brand, design, hosted API convenience, support, service-level agreements, enterprise analytics, continuous maintenance, and white-label components.

Potential packaging:

- Free local calculation SDK
- Hosted metered API
- Commercial mobile SDK
- White-label UI component
- Enterprise licence
- Custom integration support

Before commercial release, define schema-support windows, signed artefacts, supply-chain controls, migration notes, service observability, SLA/error budgets, trademark strategy, source/reference review, and privacy terms. Payment processing is deliberately outside this prototype.
