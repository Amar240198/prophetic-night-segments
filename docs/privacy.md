# Privacy statement

Manual calculations send the supplied timetable interval to the application API. Coordinate calculations additionally send latitude, longitude, timezone, service date, calculation method, and selected timetable source to the application API. For astronomical calculations, the server forwards the relevant values to its configured prayer-time provider (`islamic.app` by default). London Unified calculations use the bundled annual timetable and do not forward coordinates to another provider. Browser location access is optional and only starts after the user selects “Use my precise location”; coordinates can always be entered manually. The application does not retain coordinates, but production operators and remote providers may process network metadata and must publish an appropriate retention policy.

Calculations and ICS downloads do not require an account or Google connection. Application code must not log request bodies. Manual mode remains available.

Optional Google Calendar connection requests event access on calendars the user owns and access to their Google email address. The app displays that email and stores it with a short-lived access token inside an encrypted, HttpOnly cookie. The server decrypts the cookie to create only the events the user selects in their primary Google Calendar. Event data includes titles, calculated timestamps, the selected timezone, and planning descriptions including the prayer-time source. Google receives those selected events. No refresh tokens or user account database are maintained; the session lasts at most one hour. Disconnect attempts to revoke Google access and clears the app cookies; existing calendar events remain in Google until the user removes them. If revocation is unavailable, the app explains how to remove access through Google Account settings. See [Google Calendar setup and storage limitations](google-calendar-setup.md).

A production operator must publish its operator identity, retention policy, subprocessors, provider disclosure, lawful basis, deletion process, and region-specific privacy terms. Clients should minimise coordinate precision to what the selected provider needs.
